# Resume_Ranker_AI

This app compares candidate resumes against a Job Description using an LLM (OpenAI) and provides:

- Matching skills
- Missing / non-matching skills
- Other strong points from the resume
- A score from 1–10
- A label: Bad, Good, or Best
- A short explanation
- Optional per-skill weighting → Weighted score 1–10
- Dashboard view, similarity heatmap, CSV/Excel export, and email-ready report
